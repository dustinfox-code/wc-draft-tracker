# 2026 World Cup Draft League — Live Tracker

Live results, league standings, and a "which game do I watch next" banner for an
8-manager World Cup team draft league.

**Live page:** https://dustinfox-code.github.io/wc-draft-tracker/

## What's here

- `index.html` — the live tracker. All client-side, no keys. Three data layers:
  1. **Schedule/bracket + canonical results**: the fast-updating
     [community mirror](https://github.com/upbound-web/worldcup-live.json) and
     the [openfootball feed](https://github.com/openfootball/worldcup.json),
     fetched in parallel — whichever has more completed results wins.
  2. **ESPN scoreboard overlay**: fills in final scores the feeds don't have
     yet (minutes after full time) and live in-game scores (polled every
     2 minutes). Feeds win once they carry a score; ESPN covers the gap.
  3. **Bundled snapshot** (`data/worldcup.json`) as last resort.

  Renders standings, group tables, schedule, and a next-match countdown for
  whichever manager's teams (plus any extra teams) the viewer follows.

  Standings also show a **live projected final total** per manager: Silver
  Bulletin republishes his Datawrapper charts nightly after each matchday, and
  their data is served from a public CDN (chart ids `1oPAd`/`EodNy`/`ArtIj`
  for group expectations, `JRO90` for the knockout ladder). The page fetches
  those CSVs at view time and runs them through the league scoring formula —
  same arithmetic as the draft board's EV, fresher inputs. Fallback chain:
  live fetch → last good fetch (localStorage) → pre-tournament numbers; the
  header shows which is in use. If Silver replaces those charts with new ones
  mid-tournament, update the ids in `DW_GROUP_CHARTS` / `DW_KO_CHART`.
  Each live or finished score with a small **↗** deep-links to that match on
  [Sofascore](https://www.sofascore.com) (new tab) for full live + post-match
  stats — xG, shots, momentum. The URLs come from `data/sofascore.json` (see
  "Updating the Sofascore links"); if that file is empty/absent the scores just
  render without a link.
- `draft.html` — the original pre-tournament draft board / simulator
  (Silver Bulletin EVs, draft-night pick tracking). Preserved as-is.
- `data/worldcup.json` — bundled snapshot of the feed, used as a fallback if
  raw.githubusercontent.com is unreachable.
- `data/sofascore.json` — `{fixture → Sofascore match URL}` map behind the ↗
  links, generated by `scripts/harvest-sofascore.mjs`.

## League scoring

| Milestone | Points |
|---|---|
| Group-stage win / draw | 3 / 1 |
| Advance to knockouts | +4 |
| Each knockout-stage win (R32, R16, QF, SF) | +5 |
| Winning the final | +10 (5 win + 5 champion bonus) |

Third-place match is not scored. Advancement (+4) is detected when a team
appears in a resolved Round-of-32 fixture in the feed.

## Rosters

Draft happened 2026-06-10; rosters were pulled from the league's shared Google
Sheet and are hardcoded in `index.html` (`ROSTERS`). If a trade ever happens,
edit that object and push.

## Updating the Sofascore links

Sofascore's API is behind Cloudflare with no CORS. It blocks on TLS
fingerprint, so Node's `fetch` gets 403'd even from a residential IP — a real
browser is required.

**Recommended — run it in your browser (no installs, always works):**

1. Open <https://www.sofascore.com> (any page on the site).
2. DevTools → Console (Chrome `Cmd-Opt-J`; Safari needs the Develop menu). If it
   warns about pasting, type `allow pasting`, Enter.
3. Paste all of `scripts/harvest-sofascore-console.js`, Enter. It downloads
   `sofascore.json` (and copies it to your clipboard).
4. Move it to `data/sofascore.json`, then `git commit && git push`.

The request is same-origin and rides your already-authenticated session — the
same call the site makes itself — so Cloudflare lets it through.

**Alternative — `scripts/harvest-sofascore.mjs`** (`node scripts/harvest-sofascore.mjs`,
Node 18+, no deps). Same logic from the CLI, but only works in an environment
Cloudflare doesn't fingerprint-block (e.g. behind `curl-impersonate`); plain
Node will 403.

A match's Sofascore `customId` is stable once assigned, so you don't need to
re-run often — just when new fixtures get scheduled:

- **once now** for the group stage (all 72 games are known), then
- **after each knockout round's draw resolves** (R32, R16, QF, SF, final — ~6
  more runs) to pick up the newly-scheduled matches.

If it prints `⚠ unresolved teams`, add the shown name/`nameCode` to
`NAME_TO_CODE` / `CODE_ALIAS` in the script and re-run.

## Updating the fallback snapshot (optional)

```sh
curl -sL https://raw.githubusercontent.com/openfootball/worldcup.json/master/2026/worldcup.json \
  -o data/worldcup.json
```
